# Godot 2D Coin Collect Assets

Shared practice assets for the Godot 2D Coin Collect tutorial books.

## Download

- Latest asset package: [coin_collect_assets.zip](https://github.com/gomsik/godot-2d-coin-collect-assets/releases/latest/download/coin_collect_assets.zip)

If the latest link does not work yet, open the Releases page and download the newest `coin_collect_assets.zip`.

- Releases: <https://github.com/gomsik/godot-2d-coin-collect-assets/releases>

## Usage

These files are provided so readers can follow along with the book exercises.
Download `coin_collect_assets.zip`, extract it, and copy the included `assets`
folder into your Godot project when the book asks you to add the practice assets.
