# Godot 4.xで作る2Dコイン収集ゲーム 日本語チュートリアル

このページは、Godot 4.xで最初の2Dゲームを作りたい方向けの日本語チュートリアル案内です。

本文はZennで無料公開しています。PDF/EPUBで手元に置きたい方、章ごとの完成サンプルZIPと比較しながら進めたい方にはGumroad版があります。

## 作るもの

方向キーまたはWASDでプレイヤーを動かし、画面に現れるコインを集める小さな2Dゲームを作ります。

実習で扱う内容:

- Godot 4.xのプロジェクト作成
- Input Mapでの移動アクション設定
- プレイヤー移動
- Area2Dを使ったコイン収集
- Signal接続
- スコア表示
- CanvasLayerを使ったHUD
- 制限時間タイマー
- 効果音
- ゲームオーバー表示
- Rキーでの再スタート
